# Blocklists

`1win.txt` uses AdGuard/uBlock Origin filter syntax.

## Apply it

1. Open the blocker's custom filters or custom lists settings.
2. Paste or import `blocklists/1win.txt`.
3. Apply the changes and clear the browser DNS cache.

This repository cannot change the PC’s DNS, hosts file, router, or browser
extension automatically. If the current blocker only supports hosts entries,
it will not understand the wildcard rule; add the listed domains individually
or use a DNS filter that supports wildcard domains.
